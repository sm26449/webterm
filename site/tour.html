Tour

What you can do once you are in.

These screenshots and short clips show EverShell running on a demo fleet. Screenshots follow your system’s light or dark theme; clips play while they are on screen, and stay still if you prefer reduced motion.

Sessions

A terminal that outlives the tab.

Sessions opened through the agent run in tmux on the host. You can close the browser, restart the gateway, or switch to your phone and return to the same process and scrollback.

  • Commands as objects. With shell integration, every command gets its exit code, duration and output in a side panel.
  • Copy a command as Markdown or choose Run again to put it back at the prompt for review before execution.
  • Several devices at once on the same session, live.

Session names

Give every session a name.

Click the title in the session header and type: import-job, top, health check. The name follows the session to the dashboard, the launcher, the split view picker and your other devices.

  • Named, not numbered. No more guessing which “Session 3” runs the import.
  • Press Enter to save; the name is stored with the session on the gateway.

New session launcher

Continue where you left off, or start fresh.

Click New session on a host where you already have live sessions and EverShell lists them first, so you pick one up instead of piling up shells.

  • Shift+click or Shift+Enter on New session skips it and opens a fresh shell.
  • Sessions already open in a tab are listed too; picking one switches to that tab.
  • Close idle… stops the sessions nobody has used for over a day, in one go.
  • Idle notices: after the number of days you set, the owner of an unused session is asked to keep it open or close it. Nothing is closed automatically.
  • Turn the launcher off for one host, or everywhere in Settings → Terminal & workspace.

Adding a host

One command on the new machine.

Add a host and EverShell gives you a one-line installer for its agent. The agent dials out to your gateway with a token bound to that machine: no open port, no stored login.

  • Linux with Python 3.6+. Older systems get a pinned, checksum-verified portable Python for the agent alone.
  • Many machines at once with a group enrollment token: expiring, revocable, use-capped and audited.
  • No agent possible? Add it as an SSH or telnet host instead.

Dashboard and hosts

The whole fleet, at a glance.

Sessions to resume, hosts grouped by folder and tag, live metrics, and a security card that tells you what needs attention.

  • Host page with CPU, memory and disk, live previews of its sessions, and agent status.
  • Threshold alerts for CPU, RAM and disk, by email or webhook.
  • Wake-on-LAN for an offline machine, through a neighbouring agent.

Split views

Several hosts, side by side.

Put two to four sessions in one view, in five layouts with draggable dividers. Save it by name and it comes back on any device.

  • Type into several panes at once, with a guardrail that stops a dangerous command before it reaches any of them.
  • Pop out a split view into its own window.

Files and editor

The file manager follows your shell.

Open Files next to the terminal and it follows the directory you are in. Select, rename, move, archive, download; open a file in a full code editor.

  • Monaco editor, the one inside VS Code, with syntax highlighting for the files you edit on the host.
  • Git panel for the repository you are in: status, commits, branches.
  • Copy between hosts without going through your laptop.

Uploads and downloads

Drop a file on the terminal.

It lands in the directory your shell is in, and its path is typed at the prompt. Large uploads resume where they stopped, and every chunk is checked.

  • One floating widget shows every transfer, and opens by itself when one needs a decision.
  • Paste a screenshot into an AI CLI running on the host: the image lands there and its path is typed for you.

Run on hosts

One command, many machines.

Pick hosts by name or tag, confirm, and watch a grid fill with the state, exit code and output of each one.

  • Saved commands are shared with the terminal's snippets, on every device.
  • Copy report as Markdown, ready for a ticket.
  • Command guardrail: rules an admin sets block or ask for confirmation before a command runs.

Port forwards

Internal web UIs, behind your login.

Grafana, Proxmox, a container's admin page bound to localhost: each gets its own subdomain, reached through the agent's tunnel. No ssh -L, and it works from an iPad.

  • HTTP, HTTPS and WebSocket, on agent and SSH hosts.
  • Isolated per forward: its own subdomain and cookie, a token bound to it, and protection against reaching hosts it should not.
  • Telnet bastion: the console of a device that only the host can reach.

Updates

Updates you can see, upgrades you control.

Each agent counts pending OS packages and the host gets a badge, red when any are security fixes. One click opens a terminal with the right upgrade command, and you press Enter.

  • apt, dnf, zypper, pacman, apk. Checked every few hours, read-only.
  • Agents update themselves from the gateway, only with an update signed with your own key, and wait while the host has sessions open.

Diagnostics

Debugging without SSH.

A host snapshot with OS, CPU, memory, every filesystem, network interfaces and routes, kept even when the host is down. Listening ports on demand, the link's health, and the agent's own log.

  • Services: systemd units with their live state, logs and start, stop or restart.
  • Docker: containers, images, live logs and stats.

Share and replay

Show someone, without an account.

A share link lets a guest watch a live session, or type in it if you allow. It expires, and you can revoke it at once: their screen is wiped.

  • Replay links share the recording of a finished session, with likely secrets masked.
  • Every open is logged and you get an alert.
  • Recordings capture terminal output, which may include text echoed by the shell.

Settings

Every setting, one search away.

Type a word such as backup, SMTP or passkey and jump straight to the section. Search understands English and Romanian.

  • Three groups: Personal (account and security, appearance, terminal, notifications), Administration (people and roles, access, policy, network, alerts, backup, updates) and Operations (system health, audit log).
  • Sections you are not allowed to change are not shown at all.
  • On a phone, Settings opens as a list with the search on top, and each section gets the full screen.

EverShell theme

A look of its own, light or dark.

The EverShell theme is the default from 3.7.1: petrol, cream and a phosphor accent, in a light and a dark variant that follow your system.

  • If you picked a theme before, you keep it.
  • Midnight and the macOS, Windows 11, GNOME and KDE families are still one click away in Settings → Appearance.

On your phone

The same session, in your pocket.

Install it as an app, and pick up the session you left on your desk. A two-row key bar gives you Esc, Tab, Ctrl and arrows; long-press selects text.

  • Notifications when a long command finishes.
  • Themes that look like macOS, Windows 11, GNOME or KDE, light or dark.

Try it on your own server.
