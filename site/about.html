About

A shell that stays where you left it.

EverShell is open source, self-hosted, and built by a small team that cares about one thing above the rest: not losing your work, and not losing your servers.

Why it exists

A long job, a closed laptop, a lost session.

Everyone who runs servers has lost work this way: a migration halfway through, the Wi-Fi drops, and the SSH session takes the process with it. tmux fixes that, if you remembered to start it, on that host, from a machine that has your key.

EverShell makes the persistent session the default, and puts it in any browser, phone included, with nothing to open on your servers. Then it adds what you reach for next: files, several hosts side by side, one command on many, and a way to show someone what you see.

First public release: August 2026. More than a hundred releases since, each with its reasons in the changelog.

How it is built

Security first, and written down.

  • Fail closed

    When a check cannot decide, the answer is no. Every change that touches security gets an independent review before it ships.

  • Agents signed offline

    Agent releases are rare, bundled, and signed with a key that never touches a networked machine.

  • Release checks

    The publish pipeline requires unit, browser and accessibility tests, a secret scan and a Python dependency audit. The image and npm scans run weekly, separately.

  • Rules on paper

    The product's business rules live in the repository, next to the code that enforces them, so the same mistake is not made twice.
