Instalare

Serverul tău, sesiunile tale.

EverShell rulează ca un singur container Docker în spatele lui Traefik, pe un server al tău. Scriptul de instalare se ocupă de restul.

De ce ai nevoie

  • Un server Linux cu Docker

    Orice distribuție care rulează Docker Compose, cu porturile 80 și 443 libere. Comanda de instalare de mai jos este pentru un server cu Ubuntu sau Debian proaspăt instalat; în rest, deploy.sh folosește Docker-ul pe care îl ai deja. Imaginea publicată e amd64; pe ARM o construiești din sursă.

  • Un domeniu care indică spre server

    Pentru HTTPS. Un token Cloudflare adaugă un certificat wildcard, care acoperă subdomeniile de port forwarding și numele agenților. Fără el, îndreaptă și agents.<domeniul tău> spre server.

  • Hosturi la care să ajungi

    Pentru agent: Linux cu Python 3.6+ și, ideal, tmux. Hosturile mai vechi primesc un Python portabil. Restul: SSH sau telnet.

Instalare pe Ubuntu sau Debian

$ git clone https://github.com/sm26449/webterm.git
$ cd webterm
$ git checkout v3.7.1
$ less install.sh    # rulează ca root: citește-l
$ sudo ./install.sh --domain term.example.com \
      --email you@example.com

Pune Docker, stack-ul în /opt/webterm, un certificat Let's Encrypt, firewall-ul și un backup zilnic criptat, apoi afișează adresa și un token de configurare de unică folosință.

Primele zece minute

01

Îți faci contul

Deschizi adresa, folosești tokenul de configurare și adaugi un passkey din Settings → Sign-in & 2FA.

02

Adaugi un host

+ Add host îți dă o comandă de o linie. O rulezi pe server: creează un utilizator neprivilegiat webterm, iar hostul apare online.

03

Deschizi o sesiune

Pornești ceva, închizi tab-ul și o redeschizi de pe telefon.

Alte variante

  • Alte distribuții Linux cu Docker

    Copiezi .env.prod.example în .env, îl completezi și rulezi ./deploy.sh.

  • Single sign-on

    Cu Authentik, inclus sau al tău: deploy.sh --with-authentik.

  • Multe hosturi deodată

    Un token de înrolare de grup: o singură comandă, rulată pe fiecare mașină.

  • Upgrade-uri

    sudo ./upgrade.sh vX.Y.Z în /opt/webterm, cu rollback dacă ai nevoie.
