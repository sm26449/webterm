# EverShell brand

For work on product branding, public-facing copy, logos, icons or link previews, use the [EverShell identity guide](docs/brand/cursor/README.md). Reuse the SVGs and PNGs linked there. Use the [colour variables](docs/brand/cursor/colors.css) for brand colours.

Write **EverShell** in prose and **evershell.dev** for the domain. When using the tagline, preserve its exact wording and punctuation: **Close the tab. Keep the shell.**

For application UI components and theme tokens, follow the [design system](docs/design/DESIGN-SYSTEM.md).
