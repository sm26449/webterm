# EverShell

**Close the tab. Keep the shell.**

[Open the visual identity proof (PDF)](output/pdf/EverShell-identity.pdf)

## Name and message

Write **EverShell** in running text and **evershell.dev** for the domain. The logo spells **evershell** in lowercase. Use the tagline with both periods. For a first-time reader, the proposed short product description is “Self-hosted terminal sessions that keep running on your machines.”

## Logo and lettering

Use [cream lettering on petrol](logo-pe-petrol.svg) or [petrol lettering on cream](logo-pe-crem.svg). Both files have transparent backgrounds. The light “ever” and bold “shell” are drawn as vector outlines. The Phosphor block aligns with the two final ascenders and stays solid. Scale the whole SVG proportionally. As a spacing guide, leave at least one cursor width around the visible logo.

For single-colour reproduction, use [dark ink](logo-mono-ink.svg) or [white](logo-mono-paper.svg). For accompanying copy, use Helvetica Neue with Arial and sans-serif as fallbacks, as in the banner.
